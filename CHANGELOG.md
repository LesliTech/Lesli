# Changelog

## 5.1.13 (unreleased)

- Establish Ruby 3.3.5 and Rails 8.1 as the tested release baseline.
- Make Tailwind CSS the official styling pipeline and remove Sass/Bulma support.
- Finalize the Activity, Task, Discussion, and Attachment Item contracts,
  tenant ownership, controllers, components, translations, and tests.
- Add Active Storage-backed attachments with explicit resource allowlists.
- Improve Turbo responses, error pages, the welcome page, and responder APIs.
- Allow initialization and seed data to run with or without LesliShield.
- Adopt the shared LesliActions engine workflow and Linux lockfile platform.

See the [upgrade guide](docs/start/upgrading.md) for migration requirements.
